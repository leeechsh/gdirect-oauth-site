Personal-use desktop authorization

gdirect — Google Drive access from your terminal

A personally configured OAuth client for using the open-source gdirect desktop command-line tool to browse, download, upload, and mount Google Drive files.

This page explains the purpose of this OAuth client, the permissions it requests, and how it handles your information.

How your data is handled

Browse & download

List Google Drive folders and download your selected files through the desktop tool.

Upload & manage

Transfer files to Google Drive and use supported file operations after granting access.

Optional local mount

Access Drive via a local mounted filesystem, with temporary local caching where applicable.

Why this app requests Google Drive access

The desktop tool requests https://www.googleapis.com/auth/drive, which can allow it to view, download, create, edit and delete files in the authorized Google Drive account. This is a broad permission needed for the tool's full functionality; only authorize it for an account you trust.

How authorization works

You initiate Google sign-in through the desktop tool. Google handles the consent flow. The utility connects to Google services to carry out your requested file operations and stores authorization credentials and settings on the computer where it runs. Depending on features used, downloads and mounted files may also be stored locally.

Personal configuration, not an upstream service. This OAuth client is separately configured for personal use with the independent open-source project mizorewww/gdirect. This website does not run a Google sign-in page or accept Google Drive files.
